# Neural Network



## What is a Neural Network?



A neural network is a computational model inspired by the human brain.



It consists of interconnected artificial neurons.



## Basic Structure



A simple neural network usually contains:



* Input layer
* Hidden layer
* Output layer



## What I Learned



A neural network learns by adjusting the weights of connections between neurons.
